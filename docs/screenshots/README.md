# Screenshot checklist

Capture actual screenshots of your LinkForge deployment. Use these suggested filenames:

1. `dashboard.png` — Entire dashboard with summary metrics and link list, ideally desktop width.
2. `analytics-qr.png` — Selected link's seven-day chart and QR code.
3. `architecture.png` — Export the Mermaid diagram in `docs/architecture.md` as PNG (optional; editable source is already in Markdown).

Before sharing, **hide personal email addresses, AWS account IDs, credentials, authorization tokens, private URLs, and unrelated browser tabs**. Use test links/destinations where possible.

Screenshots have not yet been provided in this documentation pack. The README references these filenames as placeholders; update them if you choose different names.
